Part 3 · the proposal

agent-tracker: one writer, readers only

Options for what triggers the writes

B · hooks + statusline tick (chosen)written when it happens, only then: no lag, no work while idle. A crash sends no end, so boot_ts + last seen cover it.
A · nothing stored, read Claude Code's files~/.claude/sessions is gone after a crash; no history, no last prompt, no Codex.
C · a daemon polling every N salways running, up to N s late, misses short Claude sessions, still needs a hook for the prompt time.
D · one SQLite file written by every hookevery hook of 10+ Claude sessions takes the same lock; a hook must be fast and never fail. OK later as a read cache.
E · keep it as today13 mechanisms, 4 "alive?" rules, and each new need adds a copy (as resurrect did today).

Write collisions

Who writes at the same timeSame file?Why it is safe
two Claude sessionsnoone file each
two hooks of one Claude session (subagents)yeseach event is one append of < 512 B (>>): appended whole, lines never mixed. To test on APFS in step 2.
statusline ticksyestouch only sets a time: the last one wins, which is the right answer
a reader during a write · a power cut mid-write—a line without its final newline is ignored
today: the heartbeat file, written by every Claude sessionyeslast writer wins, so it can't tell which Claude session is open; replaced by seen/<uuid>

Reading "open at crash", worked on today's crash

open-at-crash:
  prev_boot = the boot_ts before the current kern.boottime
  for each Claude session with events in prev_boot:
    skip if its last event is "end"
    skip if a later "start" in prev_boot took the same pane %id     # the pane was reused
    → row(UUID, pane, folder, last prompt, last seen)

today, with asm's files only:   47 "never ended" since October   (no boot_ts, no pane reuse rule)
with the tracker:               only Claude sessions of the 11:12 boot, one per pane

Decision for you: there are two crash restores today. terminal_snapshot.py (1 Nov) brings back tmux, the iTerm2 tabs and each Claude session, but only when run by hand. resurrect + continuum (set up today) brings back tmux only, with Claude panes empty, and saved 2 times in 30 min instead of 6.
